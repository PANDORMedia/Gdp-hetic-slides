# Gestion de Projet — UML, Git & Collaboration

Slides de formation Gestion de Projet couvrant Use Cases, UML, Git collaboratif, reviews, conflits et release.

Projets reels : **Flipper** ou **Robotique** — Livrable : Cahier des Charges technique v1.

## Contenu

- **Jour 1** : Du besoin aux use-cases, UML utile, repo collaboratif
- **Jour 2** : Reviews, conflits Git, CI legere, release & versioning

## Utilisation

### Local (recommande)
Lancer un serveur local pour activer le panneau TP (chargement des enonces).

- Linux/macOS : `scripts/serve.sh`
- Windows : `scripts/serve.bat`

Puis ouvrir `http://localhost:8000/`.

### Navigation
- `<-` `->` : slides precedente/suivante
- `N` : notes orateur
- `F` : plein ecran
- `T` : panneau TP
- `A` : mode assistance
- `1` `2` : acces direct Jour 1/2

### GitHub Pages
1. `Settings -> Pages` -> Source: `main` / `(root)`
2. Ajouter le fichier `.nojekyll` (deja present) pour servir les `.md` bruts.
3. Ouvrir `https://<user>.github.io/<repo>/slides/`
