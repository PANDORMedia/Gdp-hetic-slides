# Plan — Gestion de Projet (2 jours)

Projet : **votre projet reel** (Flipper ou Robotique) — Livrable final : **Cahier des Charges technique v1**

Equipes : 3-4 personnes, roles tournants (PM/Analyste, Dev A, Dev B, Reviewer/Release)

Regle d'or : tout ce qui est produit (vision, use cases, UML, architecture, stack, risques) vit dans le repo, dans `docs/cdc-technique.md`.
